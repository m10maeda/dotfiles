# Mio's dotfiles

This repository contains my development environment configuration to make system setup reproducible and portable.

It mainly manages settings for Vim, Zsh, and Homebrew.

## Supported Environment

- macOS
- Zsh
- Vim

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/m10maeda/dotfiles.git ~/dotfiles
```

### 2. Run setup script

```bash
~/dotfiles/install.sh
```

## Update

```bash
~/dotfiles/update.sh
```
